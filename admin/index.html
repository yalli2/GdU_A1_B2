GitHub 저장 연결

저장 버튼을 누르면 두 사이트(GdU, GdU_A1_B2)의 access.json이 동시에 바뀝니다. 이 기기에서 한 번만 토큰을 넣어 두면 됩니다.

  1. github.com → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → GdU, GdU_A1_B2 선택
  3. Permissions → Repository permissions → Contents: Read and write → Generate → 토큰을 아래에 붙여넣기
